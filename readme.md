# MayDay-404 - Real-Time Console ATC Simulator
CL2001 Data Structures, BCS-3, Fall 2026

A console air-traffic-control game. You are the Chief Routing Officer (CRO) of
BlackBox Airline: land flights, intercept hijacks and war aircraft, counter
cyber attacks and find missing flights within 30 ticks. All data structures
are hand-made (no STL).
